# Licensing

This repository is a fork of [WebKit](https://webkit.org) with ad blocking and
privacy features added. It has no single license. Each file states its own in its
header, and the parts fall into these groups:

| Part | License | Where |
|---|---|---|
| Most of WebKit (WTF, WebKit, much of WebCore and JavaScriptCore, Apple's tools) | BSD 2-clause | file headers |
| WebCore and JavaScriptCore code derived from KDE's KHTML and KJS | LGPL 2 or 2.1, or any later version | file headers; `Source/JavaScriptCore/COPYING.LIB`, `Source/WebCore/LICENSE-LGPL-2.1` |
| Ad blocking integration and its tests, including code ported from Brave | MPL 2.0 | `SPDX-License-Identifier: MPL-2.0` headers, e.g. `Source/WebKit/NetworkProcess/AdBlock/`, `Source/ThirdParty/AdblockRust/`; `LICENSES/MPL-2.0.txt` |
| Third-party code under `Source/ThirdParty/` and elsewhere | as stated in each component | that component's own license file |

## Code added by this fork

New files are copyright Artem Polunin and licensed under MPL 2.0 unless the
header says otherwise. Changes to existing WebKit files are under that file's
existing license, normally BSD 2-clause, so they can be contributed back
upstream.

Some files contain code from [Brave](https://github.com/brave/brave-core), which
is also MPL 2.0. Those files keep Brave's copyright notice next to ours. The
Rust bridge in `Source/ThirdParty/AdblockRust/` is the main one, and its
`README.md` lists what came from where.

## Binaries

A build with ad blocking enabled links `libwebkitadblock.a` into WebKit.framework.
That library contains Rust crates under MIT, Apache 2.0, Unicode 3.0, Zlib,
Unlicense and MPL 2.0. Anyone distributing the framework must include their
license texts, generated by `Source/ThirdParty/AdblockRust/scripts/generate-notices.py`
from the exact dependency versions in `Cargo.lock`. Distributing
the framework also means making its source available: the LGPL and MPL 2.0
parts require it.

Filter lists and the scriptlet resource library are not part of this repository.
The browser loads them at runtime, and they carry their own licenses.
